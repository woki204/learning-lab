# 🎓 מעבדת למידה — Learning Lab

מערכת לבניית **סביבות למידה אינטראקטיביות**: כל סביבה בנויה משלבים (שקופיות),
עם סרגל ניווט מספרי בתחתית המסך, מצבי תצוגה למרצה, מצב לומד ציבורי ותעודת סיום
אוטומטית בסוף התהליך.

## מה יש במערכת

| תפקיד | כניסה | יכולות |
| --- | --- | --- |
| **מנהל מערכת** | שם משתמש + סיסמה | רישום מרצים חדשים, קביעת סיסמה ראשונית, השעיית משתמשים |
| **מרצה / יוצר** | שם משתמש + סיסמה | בניית סביבות, מעבר בין מצב עריכה ↔ תצוגה ↔ לומד, שינוי סיסמה, קישור שיתוף |
| **לומד** | ללא כניסה — רק קישור | מצב לומד בלבד, ובסופו תעודה |

**פרטיות הלומדים:** המערכת אינה שומרת דבר על הלומדים — לא שם, לא תשובות, לא ציון.
הכול חי בזיכרון הדפדפן ונעלם בסגירת הלשונית. התעודה נוצרת מקומית וניתנת להדפסה
או לשמירה כ-PDF.

## הקמה מקומית

```bash
npm install
npm run dev
```

## Firebase — פרויקט משותף

המערכת רצה על פרויקט Firebase קיים, **`eduai-planner-1b6ac`**, שמשרת גם את אתר
הפורטפוליו. ההגדרות כבר בקוד ([`src/lib/firebase.js`](src/lib/firebase.js)) ואין
צורך לשנות דבר.

כדי לא להתנגש בנתוני הפורטפוליו (`users`, `apps`, `clicks`, `favCounts`), כל מה
ששייך למערכת הזו יושב בקולקציות עם תחילית **`ll_`**:

| קולקציה | תוכן |
| --- | --- |
| `ll_users` | פרופילי מנהלים ומרצים |
| `ll_courses` | סביבות הלמידה |
| `ll_meta` | מסמך נעילה חד-פעמי של ההקמה |

### כללי אבטחה — שיפור מומלץ, לא חובה

המערכת עובדת עם הכללים הקיימים בפרויקט כפי שהם. עם זאת, הכללים הנוכחיים
מתירים קריאה ציבורית רחבה, ולכן מומלץ להדק אותם.

כשתגיע לזה: פתח **Firestore → Rules** ושתול את הבלוקים מתוך
[`firestore.rules`](firestore.rules) **בתוך** הכללים הקיימים —
אל תחליף את כל התוכן, זה ינתק את הפורטפוליו מהנתונים שלו.

### יצירת מנהל המערכת הראשון

**אין צורך לגעת בקונסול.** היכנס פעם אחת ל-
`https://woki204.github.io/learning-lab/#/setup`, בחר שם משתמש וסיסמה, וזהו.

העמוד יוצר גם את חשבון ההזדהות וגם את פרופיל המנהל, ובאותה פעולה כותב מסמך
נעילה `ll_meta/bootstrap`. מרגע זה העמוד נעול לתמיד ומשתמשים חדשים נרשמים רק
מתוך **ניהול משתמשים** שבאתר.

> שמות משתמש ממופים פנימית לכתובת `<username>@users.learning-lab.local`,
> כי Firebase Auth דורש דוא"ל. המשתמשים לעולם לא רואים את זה.

## פרסום ל-GitHub Pages

הריפו מגיע עם workflow מוכן. פעם אחת:
**Settings → Pages → Source: GitHub Actions.** מכאן כל דחיפה ל-`main` מתפרסמת אוטומטית.

הכתובת תהיה `https://<user>.github.io/learning-lab/`.
אם תשנה את שם הריפו — עדכן את `base` ב-[`vite.config.js`](vite.config.js) בהתאם.

### הוספת כלי חדש

כל הכלים מרוכזים ב-[`src/lib/blocks.js`](src/lib/blocks.js). כדי להוסיף כלי:

1. הוסף רשומה ל-`BLOCK_TYPES` עם `label`, `icon`, `create()` — ואם הכלי נבדק,
   גם `gradable: true` ו-`grade(block, answer)`.
2. הוסף את התצוגה שלו ב-`BlockRenderer.jsx` ואת העריכה ב-`BlockEditor.jsx`.

הכלי יופיע אוטומטית בתפריט "הוסף כלי", וייכלל אוטומטית בציון ובתעודה.

### הכלים הקיימים

| קטגוריה | כלים |
| --- | --- |
| טקסט | כותרת ראשית · כותרת משנה · טקסט · טקסט משני — עם גופן, גודל, צבע, הדגשות, יישור, כיוון כתיבה, מילוי ומסגרת |
| תמונות | מאגר תמונות אישי, גרירה לשקופית, מסגרת ופינות |
| וידאו ושמע | הטמעה מיוטיוב, מ-Vimeo או מקובץ — עם שנייית התחלה · נגן שמע להסכתים · גלריית תמונות |
| שאלות | שאלה אמריקאית (רשימה או כרטיסים עם תמונות, או סקר עמדה ללא תשובה נכונה) · בחירה מרובה · השלמת מילים (הקלדה או רשימה נפתחת) · מיון לקבוצות · התאמה בין טורים · שאלה פתוחה |
| כרטיסים | תיבות מסומנות (הידעת · טיפ · גוף ידע · כלי חדש · מילה חמה · שימו לב) · כרטיס כלי · כרטיס מקור · חשיפה בלחיצה · לשוניות |
| בדיקה | כפתור בדיקה בתוך השלב, עם ניקוד, סימון תשובות וניסיון חוזר |
| שקופית | רקע בצבע או בתמונה |

**בדיקה בתוך השלב:** רכיב "כפתור בדיקה" בודק את כל השאלות שבאותו שלב, מסמן מה נכון
ומה לא, ומציג ניקוד. התעודה בסוף עדיין מסכמת את כל הסביבה.

**משוב מדורג:** לכל שאלה אפשר להגדיר משוב לתשובה נכונה, משוב לתשובה שגויה, הסבר
כללי, ובשאלה אמריקאית גם משוב נפרד לכל מסיח. הכול נחשף יחד אחרי הבדיקה.

**תשובות שאינן מנוקדות** — שאלה פתוחה וסקר עמדה — אינן משפיעות על הציון, אבל
נאספות ומוצגות בתעודה.

### תחביר השלמת המילים

בתוך הטקסט של רכיב "השלמת מילים":

| כתיבה | מה הלומד רואה |
| --- | --- |
| `[[]]` | שדה הקלדה. כל תשובה שאינה ריקה מתקבלת |
| `[[מים\|חיסכון]]` | שדה הקלדה. מתקבלת אחת מהתשובות האלה |
| `{{דומה\|*שונה}}` | רשימה נפתחת. הכוכבית מסמנת את הנכונה |

ההשוואה מתעלמת מרווחים כפולים, מפיסוק ומאותיות גדולות/קטנות.

### מילה חמה

בכל שדה טקסט — תיבת טקסט, לשונית או תוכן נחשף — אפשר לכתוב
`((גזוזטרה|מרפסת))`. המילה הראשונה מוצגת מודגשת, ובלחיצה עליה נפתח ההסבר.

### ערבוב סדר

שאלה, בחירה מרובה, מיון והתאמה יכולים להציג את האפשרויות בסדר אקראי, כדי
שלא ייווצר דפוס קבוע. הסדר נקבע פעם אחת לכל רכיב ונשאר יציב כל עוד הלומד
נמצא בשלב, כך שהרשימה לא קופצת תוך כדי מענה.
